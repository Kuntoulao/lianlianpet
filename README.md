# 莲莲 (Lianlian)
将vesper文件夹放入.codex/pets即可
Custom animated pet asset, sprite version 2.

## Files

- `vesper/pet.json` — pet metadata.
- `vesper/spritesheet.webp` — transparent 8 × 11 sprite atlas (1536 × 2288 px, 192 × 208 px cells).
- `preview.png` — labeled atlas preview.
- `jumping-preview.gif` — five-frame jump animation preview.
